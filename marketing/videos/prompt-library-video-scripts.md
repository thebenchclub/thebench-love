# Prompt Library — Social Video Scripts
**Format:** 9:16 vertical · **Duration:** 30 seconds each · **Platform:** Facebook & Instagram Reels/Stories

---

## Production Notes (apply to all videos)
- **Safe zone:** Keep all text within center 80% of frame (accounts for platform UI chrome)
- **Font:** Bold, high-contrast white or yellow `#f4d03f` on dark `#0a0a0f` background
- **Pacing:** On-screen text changes every 2–3 seconds
- **Sound-off:** All key messages must read in captions alone — many viewers watch muted
- **CTA end card:** Last 5 seconds freeze on CTA with URL — hold long enough to read and tap
- **Hook:** First 3 seconds must earn the scroll-stop — use pattern interrupts (bold text slam, motion)
